# Daily Dash API — foundation and My Day MVP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/api`, a Fastify + zod API over Supabase Postgres with row-level security and Supabase Auth, serving the My Day MVP (profile, routine, check-in, pillars, week, word, affirmations) with an Auth0 token exchange for RecoverySky users, fully tested at four layers.

**Architecture:** One package. SQL migrations (Supabase CLI) own the schema, RLS and seed functions; drizzle is only a typed query builder that runs every query inside a per-request transaction carrying the caller's JWT claims, so Postgres enforces isolation. Routes are thin: zod parse → domain rule or repository → reply. The OpenAPI document is generated from the same zod schemas and checked in.

**Tech Stack:** Node 22, TypeScript 5.9, pnpm 10, Fastify 5, fastify-type-provider-zod 7, @fastify/swagger 9, zod 4, drizzle-orm 0.45, postgres 3, jose 6, @supabase/supabase-js 2, supabase CLI 2 (npm), vitest 5, @jenova-marie/wonder-logger 2.3, @jenova-marie/ts-rust-result 2.2, pgTAP.

**Spec:** `docs/superpowers/specs/2026-09-22-api-my-day-design.md`

## Global Constraints

- Package name `@daily-dash/api`, path `apps/api`, private. Engines: `node >=22`, `pnpm >=10`.
- TypeScript `^5.9` (not 7.x). ESM, `module: NodeNext`, `strict`, `noUncheckedIndexedAccess`, `noUnusedLocals`, `noUnusedParameters`, `noImplicitReturns`. Copy the RecoverySky API `tsconfig.json` verbatim (Task 1).
- Private packages come from `http://git.rso/api/packages/jenova-marie/npm/` via `~/.npmrc`; the Docker build mounts `.npmrc` as a secret, never copies it.
- Logging only through `@jenova-marie/wonder-logger` (`createLoggerFromConfig` + `withTraceContext`), configured by `apps/api/wonder-logger.yaml`. Never log a raw user id, `sub`, email, token or device id; use `hashUserId()` (SHA-512, first 16 hex chars) — identical to the RecoverySky API.
- Domain and db code return `Result` values from `@jenova-marie/ts-rust-result`; only the route boundary throws or replies.
- Every per-user table: `id uuid pk default gen_random_uuid()`, `user_id uuid not null default auth.uid() references auth.users(id) on delete cascade`, `created_at`, `updated_at`, RLS enabled, four policies `user_id = auth.uid()` for role `authenticated`, no grants to `anon`.
- Error body shape everywhere: `{ "error": { "code", "message", "details"? } }`; codes: `validation`, `unauthorized`, `forbidden`, `not_found`, `conflict`, `limit_reached`, `rate_limited`, `internal`.
- All routes under `/v1` except `/healthz`, `/readyz`, `/openapi.json`. Every response carries `X-Request-Id`.
- Dates in the API are `YYYY-MM-DD` in the profile's IANA timezone; future dates are rejected where the spec says so; date windows are capped at 92 days.
- Copy rules in any user-facing string: never "failed", "missed", "behind", "overdue", "streak".
- Coverage thresholds: 95 % lines on `src/domain/**` and `src/contract/**`, 85 % overall.
- Commit after every task with a message ending in the attribution line the session reminder gives.

## Review Focus

1. A profile whose `timezone` is west of UTC at 23:30 local: `GET /today` with no `date` must return the local day, not tomorrow's UTC day. (Task 7 pins `localDate()`; Task 14 pins the route.)
2. `PUT /checkins/:date` for a date more than one day in the past must be refused with `conflict` and a message that names the edit window, while yesterday's is accepted. (Task 11.)
3. A routine item deleted (`is_active=false`) after it was ticked must still count in that week's `n of 7` history and still appear in `GET /weeks/:sunday`, but not in `GET /today`. (Tasks 10 and 13.)
4. `POST /v1/auth/exchange` called twice concurrently for a brand-new Auth0 `sub` must not create two Supabase users. (Task 15: unique index on `app_metadata->>'auth0_sub'` plus retry-on-conflict.)
5. A body that passes zod but references another user's `pillar_id` must fail as a client error (`validation` on a check-in, `not_found` on a pillar action or affirmation), never `internal` — RLS hides the row and the `check_same_user()` trigger is the backstop. (Tasks 6, 11, 12, 13.)

```ts
import { createClient } from "@supabase/supabase-js";

const url = process.env.SUPABASE_URL!;
const service = process.env.SUPABASE_SERVICE_ROLE_KEY!;
const anon = process.env.SUPABASE_ANON_KEY!;
const admin = createClient(url, service, { auth: { persistSession: false, autoRefreshToken: false } });
const pub = createClient(url, anon, { auth: { persistSession: false, autoRefreshToken: false } });

const sub = "auth0|spike-" + Date.now();
const email = `${sub.replace(/[^a-z0-9]/gi, "").toLowerCase()}@auth0.invalid`;

const created = await admin.auth.admin.createUser({
  email,
  email_confirm: true,
  app_metadata: { auth0_sub: sub },
});
if (created.error) throw created.error;

const link = await admin.auth.admin.generateLink({ type: "magiclink", email });
if (link.error) throw link.error;
const tokenHash = link.data.properties.hashed_token;

const session = await pub.auth.verifyOtp({ token_hash: tokenHash, type: "magiclink" });
if (session.error) throw session.error;

console.log(JSON.stringify({
  userId: created.data.user.id,
  accessTokenPrefix: session.data.session?.access_token.slice(0, 20),
  refreshTokenPresent: Boolean(session.data.session?.refresh_token),
  expiresIn: session.data.session?.expires_in,
}, null, 2));
```

- [ ] **Step 6: Write the config loader**

`apps/api/src/config.ts`:
```ts
import { z } from "zod";
import { createRequire } from "node:module";

const require = createRequire(import.meta.url);
const pkg = require("../package.json") as { version: string };

const schema = z.object({
  NODE_ENV: z.enum(["development", "test", "production"]).default("development"),
  PORT: z.coerce.number().int().positive().default(4100),
  SERVICE_NAME: z.string().default("daily-dash-api"),
  SUPABASE_URL: z.string().url(),
  SUPABASE_ANON_KEY: z.string().min(1),
  SUPABASE_SERVICE_ROLE_KEY: z.string().min(1),
  SUPABASE_JWT_SECRET: z.string().min(32).optional(),
  DATABASE_URL: z.string().url(),
  DATABASE_POOL_MAX: z.coerce.number().int().positive().default(10),
  AUTH0_ISSUER: z.string().url().default("https://meetingmaker.auth0.com/"),
  AUTH0_JWKS_URI: z.string().url().default("https://meetingmaker.auth0.com/.well-known/jwks.json"),
  AUTH0_AUDIENCE: z.string().min(1),
  AUTH0_JWKS_TIMEOUT_MS: z.coerce.number().int().positive().default(3000),
});

export type Config = {
  service: { name: string; version: string; port: number; env: "development" | "test" | "production" };
  supabase: { url: string; anonKey: string; serviceRoleKey: string; jwtSecret?: string; jwksUrl: string };
  database: { url: string; poolMax: number };
  auth0: { issuer: string; jwksUri: string; audience: string; jwksTimeoutMs: number };
  limits: { dateWindowDays: 92; routineWarnAt: 12 };
};

export function loadConfig(env: NodeJS.ProcessEnv = process.env): Config {
  const parsed = schema.safeParse(env);
  if (!parsed.success) {
    const names = parsed.error.issues.map((i) => i.path.join(".")).join(", ");
    throw new Error(`Invalid configuration: ${names}`);
  }
  const e = parsed.data;
  return {
    service: { name: e.SERVICE_NAME, version: pkg.version, port: e.PORT, env: e.NODE_ENV },
    supabase: {
      url: e.SUPABASE_URL,
      anonKey: e.SUPABASE_ANON_KEY,
      serviceRoleKey: e.SUPABASE_SERVICE_ROLE_KEY,
      jwtSecret: e.SUPABASE_JWT_SECRET,
      jwksUrl: `${e.SUPABASE_URL.replace(/\/$/, "")}/auth/v1/.well-known/jwks.json`,
    },
    database: { url: e.DATABASE_URL, poolMax: e.DATABASE_POOL_MAX },
    auth0: {
      issuer: e.AUTH0_ISSUER,
      jwksUri: e.AUTH0_JWKS_URI,
      audience: e.AUTH0_AUDIENCE,
      jwksTimeoutMs: e.AUTH0_JWKS_TIMEOUT_MS,
    },
    limits: { dateWindowDays: 92, routineWarnAt: 12 },
  };
}
```

```ts
export type ApiErrorKind =
  | "ValidationError" | "Unauthorized" | "Forbidden" | "NotFound"
  | "Conflict" | "LimitReached" | "TooManyRequests" | "InternalError";

export interface ApiError extends DomainError {
  readonly kind: ApiErrorKind;
  readonly code: ErrorCode;
  readonly statusCode: number;
  readonly details?: unknown;
}

function make(kind: ApiErrorKind, code: ErrorCode, statusCode: number) {
  return (message: string, details?: unknown): ApiError => ({ kind, code, statusCode, message, details });
}

export const unauthorized = make("Unauthorized", "unauthorized", 401);
export const forbidden = make("Forbidden", "forbidden", 403);
export const notFound = make("NotFound", "not_found", 404);
export const conflict = make("Conflict", "conflict", 409);
export const limitReached = make("LimitReached", "limit_reached", 422);
export const rateLimited = make("TooManyRequests", "rate_limited", 429);
export const internal = make("InternalError", "internal", 500);

export function toHttp(e: ApiError): { status: number; body: { error: { code: ErrorCode; message: string; details?: unknown } } } {
  const error: { code: ErrorCode; message: string; details?: unknown } = { code: e.code, message: e.message };
  if (e.details !== undefined) error.details = e.details;
  return { status: e.statusCode, body: { error } };
```

```ts
import Fastify, { type FastifyInstance } from "fastify";
import { randomUUID } from "node:crypto";
import type { Logger } from "pino";
import type { Config } from "./config.js";
import { notFound, internal, replyWithError, validation } from "./errors/results.js";

export type AppDeps = {
  config: Config;
  logger: Logger;
};

declare module "fastify" {
  interface FastifyRequest {
    log: Logger;
    requestId: string;
  }
}

export async function buildApp(deps: AppDeps): Promise<FastifyInstance> {
  const app = Fastify({ logger: false, trustProxy: true, genReqId: (req) => (req.headers["x-request-id"] as string | undefined) ?? randomUUID() });

  app.addHook("onRequest", async (request, reply) => {
    request.requestId = request.id;
    reply.header("x-request-id", request.id);
    request.log = deps.logger.child({ requestId: request.id, method: request.method, path: request.url.split("?")[0] });
  });

  app.addHook("onResponse", async (request, reply) => {
    request.log.info({ statusCode: reply.statusCode, ms: Math.round(reply.elapsedTime) }, "request completed");
  });

  app.get("/healthz", async () => ({ status: "ok" }));

  app.setNotFoundHandler((request, reply) =>
    replyWithError(reply, notFound(`Route ${request.method} ${request.url.split("?")[0]} not found`)),
  );

  app.setErrorHandler((error, request, reply) => {
    const e = error as Error & { validation?: unknown; statusCode?: number; code?: string };
    if (e.validation || e.code === "FST_ERR_VALIDATION") {
      return replyWithError(reply, validation("Request failed validation", e.validation));
    }
    request.log.error({ err: error }, "unhandled error");
    return replyWithError(reply, internal("Internal error"));
  });

  return app;
}
```

```ts
import { z } from "zod";

const zones = new Set(Intl.supportedValuesOf("timeZone").concat("UTC"));

export const DateString = z
  .string()
  .regex(/^\d{4}-\d{2}-\d{2}$/, "expected YYYY-MM-DD")
  .refine((s) => {
    const [y, m, d] = s.split("-").map(Number) as [number, number, number];
    const dt = new Date(Date.UTC(y, m - 1, d));
    return dt.getUTCFullYear() === y && dt.getUTCMonth() === m - 1 && dt.getUTCDate() === d;
  }, "not a calendar date");
export type DateString = z.infer<typeof DateString>;

export const IanaTimezone = z.string().refine((s) => zones.has(s), "unknown IANA timezone");

export const UuidParam = z.object({ id: z.string().uuid() });

export const ErrorResponse = z.object({
  error: z.object({
    code: z.enum(["validation", "unauthorized", "forbidden", "not_found", "conflict", "limit_reached", "rate_limited", "internal"]),
    message: z.string(),
    details: z.unknown().optional(),
  }),
});

export const errorResponses = {
  400: ErrorResponse, 401: ErrorResponse, 404: ErrorResponse,
  409: ErrorResponse, 422: ErrorResponse, 500: ErrorResponse,
} as const;

export const Warnings = z.array(z.enum(["long_routine"]));
```

```ts
import { sql } from "drizzle-orm";
import type { Config } from "../config.js";
import { schema } from "./schema.js";

export type Claims = { sub: string; role: "authenticated"; [k: string]: unknown };
export type Orm = PostgresJsDatabase<typeof schema>;
export type UserTx = Parameters<Parameters<Orm["transaction"]>[0]>[0];

export type Db = {
  sql: postgres.Sql;
  orm: Orm;
  withUser<T>(claims: Claims, fn: (tx: UserTx) => Promise<T>): Promise<T>;
  close(): Promise<void>;
};

/**
 * The connection role must be allowed to `set role authenticated` (postgres locally;
 * in production a role granted `authenticated`). Every user query runs inside withUser().
 */
export function createDb(config: Config): Db {
  const client = postgres(config.database.url, { max: config.database.poolMax, prepare: false });
  const orm = drizzle(client, { schema });
  return {
    sql: client,
    orm,
    withUser: (claims, fn) =>
      orm.transaction(async (tx) => {
        await tx.execute(sql`select set_config('request.jwt.claims', ${JSON.stringify(claims)}, true)`);
        await tx.execute(sql`set local role authenticated`);
        return fn(tx);
      }),
    close: () => client.end({ timeout: 5 }),
  };
}
```

```ts
import { and, asc, eq, gte, lte, sql, inArray } from "drizzle-orm";
import type { UserTx } from "../client.js";
import { checklistItems, checklistCompletions, routineTemplates } from "../schema.js";

export type ChecklistItem = typeof checklistItems.$inferSelect;
export type Completion = typeof checklistCompletions.$inferSelect;
export type TemplateItem = { title: string; bucket: ChecklistItem["bucket"]; time_of_day?: string };

export const routineRepo = {
  listItems(tx: UserTx, opts: { includeInactive?: boolean }): Promise<ChecklistItem[]> {
    return tx.select().from(checklistItems)
      .where(opts.includeInactive ? undefined : eq(checklistItems.isActive, true))
      .orderBy(asc(checklistItems.sortOrder), asc(checklistItems.createdAt));
  },

  async createItem(tx: UserTx, input: { title: string; bucket: ChecklistItem["bucket"]; timeOfDay?: string | null; sortOrder?: number; templateKey?: string | null }): Promise<ChecklistItem> {
    const [row] = await tx.insert(checklistItems).values({
      title: input.title, bucket: input.bucket, timeOfDay: input.timeOfDay ?? null,
      sortOrder: input.sortOrder ?? 0, templateKey: input.templateKey ?? null,
    }).returning();
    return row!;
  },

  async updateItem(tx: UserTx, id: string, patch: Partial<Pick<ChecklistItem, "title" | "bucket" | "timeOfDay" | "sortOrder" | "isActive">>): Promise<ChecklistItem | null> {
    const [row] = await tx.update(checklistItems).set(patch).where(eq(checklistItems.id, id)).returning();
    return row ?? null;
  },

  async reorder(tx: UserTx, ids: string[]): Promise<number> {
    let n = 0;
    for (const [i, id] of ids.entries()) {
      const rows = await tx.update(checklistItems).set({ sortOrder: i }).where(eq(checklistItems.id, id)).returning({ id: checklistItems.id });
      n += rows.length;
    }
    return n;
  },

  async setTick(tx: UserTx, input: { itemId: string; date: string; completed: boolean }): Promise<Completion | null> {
    const visible = await tx.select({ id: checklistItems.id }).from(checklistItems).where(eq(checklistItems.id, input.itemId));
    if (visible.length === 0) return null;
    const [row] = await tx.insert(checklistCompletions)
      .values({ itemId: input.itemId, date: input.date, completed: input.completed, completedAt: input.completed ? new Date() : null })
      .onConflictDoUpdate({
        target: [checklistCompletions.itemId, checklistCompletions.date],
        set: { completed: input.completed, completedAt: input.completed ? new Date() : null },
      }).returning();
    return row ?? null;
  },

  completionsBetween(tx: UserTx, from: string, to: string): Promise<Completion[]> {
    return tx.select().from(checklistCompletions)

  },

  async itemsByIds(tx: UserTx, ids: string[]): Promise<ChecklistItem[]> {
```

```ts
import { and, desc, eq, gte, lte, sql } from "drizzle-orm";
import type { UserTx } from "../client.js";
import { pillarRatings, gratitudes } from "../schema.js";

export type Rating = typeof pillarRatings.$inferSelect;
export type Gratitude = typeof gratitudes.$inferSelect;

export const checkinsRepo = {
  async get(tx: UserTx, date: string): Promise<{ ratings: Rating[]; gratitude: Gratitude | null }> {
    const ratings = await tx.select().from(pillarRatings).where(eq(pillarRatings.date, date));
    const [gratitude] = await tx.select().from(gratitudes).where(eq(gratitudes.date, date));
    return { ratings, gratitude: gratitude ?? null };
  },
  async put(tx: UserTx, input: { date: string; ratings: { pillarId: string; rating: number; note?: string | null }[]; gratitude?: string | null }): Promise<void> {
    for (const r of input.ratings) {
      await tx.insert(pillarRatings).values({ pillarId: r.pillarId, date: input.date, rating: r.rating, note: r.note ?? null })
        .onConflictDoUpdate({ target: [pillarRatings.pillarId, pillarRatings.date], set: { rating: r.rating, note: r.note ?? null } });
    }
    if (input.gratitude === undefined) return;
    if (input.gratitude === null || input.gratitude.trim() === "") {
      await tx.delete(gratitudes).where(eq(gratitudes.date, input.date));
    } else {
      await tx.insert(gratitudes).values({ date: input.date, entry: input.gratitude.trim() })
        .onConflictDoUpdate({ target: [gratitudes.userId, gratitudes.date], set: { entry: input.gratitude.trim() } });
    }
  },
  async delete(tx: UserTx, date: string): Promise<number> {
    const r = await tx.delete(pillarRatings).where(eq(pillarRatings.date, date)).returning({ id: pillarRatings.id });
    await tx.delete(gratitudes).where(eq(gratitudes.date, date));
    return r.length;
  },
  async between(tx: UserTx, from: string, to: string): Promise<{ ratings: Rating[]; gratitudes: Gratitude[] }> {
    const ratings = await tx.select().from(pillarRatings).where(and(gte(pillarRatings.date, from), lte(pillarRatings.date, to)));
    const gs = await tx.select().from(gratitudes).where(and(gte(gratitudes.date, from), lte(gratitudes.date, to)));
    return { ratings, gratitudes: gs };
  },
  async latestDate(tx: UserTx): Promise<string | null> {
    const [row] = await tx.select({ date: pillarRatings.date }).from(pillarRatings).orderBy(desc(pillarRatings.date)).limit(1);
    return row?.date ?? null;
  },
  async pillarKeysForRatings(tx: UserTx): Promise<Record<string, string>> {
    const rows = await tx.execute<{ id: string; key: string }>(sql`select id, key from public.pillars`);
    return Object.fromEntries(rows.map((r) => [r.id, r.key]));
```

```ts
export type DateString = string; // YYYY-MM-DD, validated at the contract boundary

const fmtCache = new Map<string, Intl.DateTimeFormat>();
function fmt(tz: string): Intl.DateTimeFormat {
  let f = fmtCache.get(tz);
  if (!f) { f = new Intl.DateTimeFormat("en-CA", { timeZone: tz, year: "numeric", month: "2-digit", day: "2-digit" }); fmtCache.set(tz, f); }
  return f;
}

/** The calendar day at `instant` in the IANA zone `tz`. */
export function localDate(instant: Date, tz: string): DateString {
  return fmt(tz).format(instant); // en-CA yields YYYY-MM-DD
}

function toUtc(d: DateString): Date {
  const [y, m, day] = d.split("-").map(Number) as [number, number, number];
  return new Date(Date.UTC(y, m - 1, day));
}
function fromUtc(dt: Date): DateString {
  return dt.toISOString().slice(0, 10);
}

export function addDays(d: DateString, n: number): DateString {
  const dt = toUtc(d); dt.setUTCDate(dt.getUTCDate() + n); return fromUtc(dt);
}
export function compareDates(a: DateString, b: DateString): -1 | 0 | 1 {
  return a < b ? -1 : a > b ? 1 : 0;
}
export function isSunday(d: DateString): boolean { return toUtc(d).getUTCDay() === 0; }
export function sundayOf(d: DateString): DateString { return addDays(d, -toUtc(d).getUTCDay()); }
export function weekDates(sunday: DateString): DateString[] {
  return Array.from({ length: 7 }, (_, i) => addDays(sunday, i));
}
export function daysBetween(from: DateString, to: DateString): number {
  return Math.round((toUtc(to).getTime() - toUtc(from).getTime()) / 86_400_000) + 1;
}
```

```ts
function dayIndex(date: DateString): number {
  const [y, m, d] = date.split("-").map(Number) as [number, number, number];
  return Math.floor(Date.UTC(y, m - 1, d) / 86_400_000);
}
function pick(list: string[], date: DateString): string | undefined {
  return list.length ? list[dayIndex(date) % list.length] : undefined;
}

/** Deterministic per (person's lists, date); no model involved. */
export function selectWord(input: WordInput): Word | null {
  const key = input.lowestPillarKey;
  if (key) {
    const own = input.own.filter((a) => a.pillarKey === key).map((a) => a.text);
    const mine = pick(own, input.date);
    if (mine) return { text: mine, pillarKey: key, source: "user" };
    const seed = pick(input.seedForPillar, input.date);
    if (seed) return { text: seed, pillarKey: key, source: "seed" };
  }
  const general = pick(input.seedGeneral, input.date);
  return general ? { text: general, pillarKey: null, source: "seed" } : null;
}
```

```ts
import * as jose from "jose";
import type { Config } from "../config.js";
import { ok, err, unauthorized, type ApiResult } from "../errors/results.js";
import type { Claims } from "../db/client.js";

export type Verifier = (token: string) => Promise<ApiResult<Claims>>;

export function createSupabaseVerifier(config: Config): Verifier {
  const issuer = `${config.supabase.url.replace(/\/$/, "")}/auth/v1`;
  const key: jose.JWTVerifyGetKey | Uint8Array = config.supabase.jwtSecret
    ? new TextEncoder().encode(config.supabase.jwtSecret)
    : jose.createRemoteJWKSet(new URL(config.supabase.jwksUrl), { timeoutDuration: 3000 });

  return async (token) => {
    try {
      const { payload } = await jose.jwtVerify(token, key as Uint8Array, { issuer });
      if (typeof payload.sub !== "string" || payload.role !== "authenticated") {
        return err(unauthorized("Token is not for an authenticated user", { code: "token_claims" }));
      }
      return ok({ ...payload, sub: payload.sub, role: "authenticated" as const });
    } catch (e) {
      const code = e instanceof jose.errors.JWTExpired ? "token_expired" : "token_invalid";
      return err(unauthorized("Token rejected", { code }));
    }
  };
}
```

```ts
  interface FastifyRequest { user: AuthUser }
  interface FastifyInstance { authenticate: (req: FastifyRequest, reply: FastifyReply) => Promise<void> }

export const authPlugin = fp(async (app, opts: { verify: Verifier }) => {
  app.decorateRequest("user", null);
  app.decorate("authenticate", async (req: FastifyRequest, reply: FastifyReply) => {
    const header = req.headers.authorization ?? "";

    const claims = r.unwrap();
    req.user = { id: claims.sub, claims };
    req.log = req.log.child({ userId: hashUserId(claims.sub) });
  });
});
```

```ts
import type { FastifyRequest } from "fastify";
import type { AppDeps } from "../app.js";
import type { Db, UserTx } from "../db/client.js";
import { internal } from "../errors/results.js";

export function requireDb(deps: AppDeps): Db {
  if (!deps.db) throw Object.assign(new Error("database not configured"), internal("Internal error"));
  return deps.db;
}

export function userTx(req: FastifyRequest, deps: AppDeps) {
  const db = requireDb(deps);
  return <T>(fn: (tx: UserTx) => Promise<T>) => db.withUser(req.user.claims, fn);
}
```

```ts
import type { FastifyInstance } from "fastify";
import type { ZodTypeProvider } from "fastify-type-provider-zod";
import { z } from "zod";
import type { AppDeps } from "../app.js";
import { errorResponses, UuidParam } from "../contract/common.js";
import { RoutineList, RoutineItem, RoutineItemCreate, RoutineItemPatch, RoutineOrder, TickParams, Tick, TemplateList, Applied } from "../contract/routine.js";
import { notFound, validation, replyWithError } from "../errors/results.js";
import { userTx } from "./helpers.js";
import { localDate, compareDates } from "../domain/dates.js";
import { longRoutineWarning } from "../domain/routine.js";
import type { ChecklistItem, Completion } from "../db/repos/routine.js";

export const hhmm = (t: string | null): string | null => (t ? t.slice(0, 5) : null);
export const toItem = (i: ChecklistItem) => ({ id: i.id, title: i.title, bucket: i.bucket, timeOfDay: hhmm(i.timeOfDay), sortOrder: i.sortOrder, isActive: i.isActive, templateKey: i.templateKey });
const toTick = (c: Completion) => ({ itemId: c.itemId, date: c.date, completed: c.completed, completedAt: c.completedAt ? c.completedAt.toISOString() : null });

export async function routineRoutes(app: FastifyInstance, deps: AppDeps) {
  const r = app.withTypeProvider<ZodTypeProvider>();
  const s = (extra: object) => ({ tags: ["routine"], security: [{ bearer: [] }], ...extra });
  const pre = { preHandler: app.authenticate } as const;

  r.get("/routine/items", { ...pre, schema: s({ response: { 200: RoutineList, ...errorResponses } }) }, async (req) => {
    const items = await userTx(req, deps)((tx) => deps.repos.routine.listItems(tx, {}));
    return { items: items.map(toItem), warnings: longRoutineWarning(items.length, deps.config.limits.routineWarnAt) };
  });

  r.post("/routine/items", { ...pre, schema: s({ body: RoutineItemCreate, response: { 201: RoutineItem, ...errorResponses } }) }, async (req, reply) => {
    const created = await userTx(req, deps)((tx) => deps.repos.routine.createItem(tx, req.body));
    return reply.status(201).send(toItem(created));
  });

  r.patch("/routine/items/:id", { ...pre, schema: s({ params: UuidParam, body: RoutineItemPatch, response: { 200: RoutineItem, ...errorResponses } }) }, async (req, reply) => {
    const row = await userTx(req, deps)((tx) => deps.repos.routine.updateItem(tx, req.params.id, req.body));
    return row ? toItem(row) : replyWithError(reply, notFound("Routine item not found"));
  });

  r.delete("/routine/items/:id", { ...pre, schema: s({ params: UuidParam, response: { 204: z.null(), ...errorResponses } }) }, async (req, reply) => {
    const row = await userTx(req, deps)((tx) => deps.repos.routine.updateItem(tx, req.params.id, { isActive: false }));
    return row ? reply.status(204).send() : replyWithError(reply, notFound("Routine item not found"));
  });

  r.put("/routine/order", { ...pre, schema: s({ body: RoutineOrder, response: { 200: z.object({ updated: z.number().int() }), ...errorResponses } }) }, async (req) => {
    const updated = await userTx(req, deps)((tx) => deps.repos.routine.reorder(tx, req.body.ids));
    return { updated };
  });

  const tick = (completed: boolean) => async (req: { params: z.infer<typeof TickParams>; user: { claims: never } } & Parameters<Parameters<typeof r.put>[2]>[0], reply: Parameters<Parameters<typeof r.put>[2]>[1]) => {
    const run = userTx(req, deps);
    const profile = await run((tx) => deps.repos.profile.get(tx));
    const today = localDate(deps.clock(), profile?.timezone ?? "UTC");
    if (compareDates(req.params.date, today) > 0) return replyWithError(reply, validation("Ticks cannot be set for a future date", { today }));
    const row = await run((tx) => deps.repos.routine.setTick(tx, { itemId: req.params.id, date: req.params.date, completed }));
    return row ? toTick(row) : replyWithError(reply, notFound("Routine item not found"));
  };
  r.put("/routine/items/:id/ticks/:date", { ...pre, schema: s({ params: TickParams, response: { 200: Tick, ...errorResponses } }) }, tick(true));
  r.delete("/routine/items/:id/ticks/:date", { ...pre, schema: s({ params: TickParams, response: { 200: Tick, ...errorResponses } }) }, tick(false));

  r.get("/routine/templates", { ...pre, schema: s({ response: { 200: TemplateList, ...errorResponses } }) }, async (req) => {
    const rows = await userTx(req, deps)((tx) => deps.repos.routine.listTemplates(tx));
    return { templates: rows.map((t) => ({ key: t.key, name: t.name, items: t.items.map((i) => ({ title: i.title, bucket: i.bucket, timeOfDay: i.time_of_day ?? null })) })) };
  });

  r.post("/routine/templates/:key/apply", { ...pre, schema: s({ params: z.object({ key: z.string().min(1).max(40) }), response: { 200: Applied, ...errorResponses } }) }, async (req, reply) => {
    const inserted = await userTx(req, deps)((tx) => deps.repos.routine.applyTemplate(tx, req.params.key));
    return inserted > 0 ? { inserted } : replyWithError(reply, notFound("Template not found"));
  });
}
```

```ts
import type { Pillar } from "../db/repos/pillars.js";
import type { Rating, Gratitude } from "../db/repos/checkins.js";
import { focalAreas, isCrisis } from "../domain/focal.js";

export function buildCheckin(date: string, ratings: Rating[], pillars: Pillar[], gratitude: Gratitude | null) {
  const byId = new Map(pillars.map((p) => [p.id, p]));
  const rated = ratings.flatMap((r) => { const p = byId.get(r.pillarId); return p ? [{ pillarId: r.pillarId, pillarKey: p.key, rating: r.rating, note: r.note, sortOrder: p.sortOrder }] : []; })
    .sort((a, b) => a.sortOrder - b.sortOrder);
  return {
    date,
    ratings: rated.map(({ pillarId, pillarKey, rating, note }) => ({ pillarId, pillarKey, rating, note })),
    gratitude: gratitude?.entry ?? null,
    focalAreas: focalAreas(rated).map(({ pillarId, pillarKey, rating }) => ({ pillarId, pillarKey, rating })),
    crisis: isCrisis(rated),
  };
}
```

```ts
import type { FastifyInstance } from "fastify";
import type { ZodTypeProvider } from "fastify-type-provider-zod";
import { z } from "zod";
import type { AppDeps } from "../app.js";
import { errorResponses } from "../contract/common.js";
import { Checkin, CheckinList, CheckinPut, DateParam, RangeQuery } from "../contract/checkins.js";
import { conflict, notFound, validation, replyWithError } from "../errors/results.js";
import { userTx } from "./helpers.js";
import { localDate, compareDates, daysBetween } from "../domain/dates.js";
import { editWindowOpen } from "../domain/checkin.js";
import { buildCheckin } from "./checkinView.js";

export async function checkinRoutes(app: FastifyInstance, deps: AppDeps) {
  const r = app.withTypeProvider<ZodTypeProvider>();
  const s = (extra: object) => ({ tags: ["checkins"], security: [{ bearer: [] }], ...extra });
  const pre = { preHandler: app.authenticate } as const;

  r.get("/checkins/:date", { ...pre, schema: s({ params: DateParam, response: { 200: Checkin, ...errorResponses } }) }, async (req, reply) => {
    const out = await userTx(req, deps)(async (tx) => {
      const { ratings, gratitude } = await deps.repos.checkins.get(tx, req.params.date);
      if (ratings.length === 0) return null;
      return buildCheckin(req.params.date, ratings, await deps.repos.pillars.list(tx, { includeInactive: true }), gratitude);
    });
    return out ?? replyWithError(reply, notFound("No check-in for that date"));
  });

  r.put("/checkins/:date", { ...pre, schema: s({ params: DateParam, body: CheckinPut, response: { 200: Checkin, ...errorResponses } }) }, async (req, reply) => {
    const run = userTx(req, deps);
    const profile = await run((tx) => deps.repos.profile.get(tx));
    const today = localDate(deps.clock(), profile?.timezone ?? "UTC");
    if (compareDates(req.params.date, today) > 0) return replyWithError(reply, validation("A check-in cannot be for a future date", { today }));
    if (!editWindowOpen(req.params.date, today)) return replyWithError(reply, conflict("A check-in can be edited until the end of the following day", { today }));

    const active = await run((tx) => deps.repos.pillars.list(tx, {}));
    const activeIds = new Set(active.map((p) => p.id));
    const sent = new Map(req.body.ratings.map((x) => [x.pillarId, x]));
    const missing = active.filter((p) => !sent.has(p.id)).map((p) => p.key);
    const unknown = [...sent.keys()].filter((id) => !activeIds.has(id));
    if (missing.length || unknown.length || sent.size !== req.body.ratings.length) {
      return replyWithError(reply, validation("Every active pillar needs exactly one rating", { missing, unknown }));
    }
    const out = await run(async (tx) => {
      await deps.repos.checkins.put(tx, { date: req.params.date, ratings: req.body.ratings, gratitude: req.body.gratitude });
      const { ratings, gratitude } = await deps.repos.checkins.get(tx, req.params.date);
      return buildCheckin(req.params.date, ratings, active, gratitude);
    });
    return out;
  });

  r.delete("/checkins/:date", { ...pre, schema: s({ params: DateParam, response: { 204: z.null(), ...errorResponses } }) }, async (req, reply) => {
    const n = await userTx(req, deps)((tx) => deps.repos.checkins.delete(tx, req.params.date));
    return n > 0 ? reply.status(204).send() : replyWithError(reply, notFound("No check-in for that date"));
  });

  r.get("/checkins", { ...pre, schema: s({ querystring: RangeQuery, response: { 200: CheckinList, ...errorResponses } }) }, async (req, reply) => {
    const { from, to } = req.query;
    if (compareDates(from, to) > 0 || daysBetween(from, to) > deps.config.limits.dateWindowDays) {
      return replyWithError(reply, validation(`from must not be after to, and the window is at most ${deps.config.limits.dateWindowDays} days`));
    }
    return userTx(req, deps)(async (tx) => {
      const pillars = await deps.repos.pillars.list(tx, { includeInactive: true });
      const { ratings, gratitudes } = await deps.repos.checkins.between(tx, from, to);
      const dates = [...new Set(ratings.map((x) => x.date))].sort();
      return { checkins: dates.map((d) => buildCheckin(d, ratings.filter((x) => x.date === d), pillars, gratitudes.find((g) => g.date === d) ?? null)) };
    });
  });
}
```

```ts
import type { AppDeps } from "../app.js";
import type { UserTx } from "../db/client.js";
import { focalAreas } from "../domain/focal.js";
import { selectWord } from "../domain/word.js";
import type { DateString } from "../domain/dates.js";

export async function wordForToday(tx: UserTx, deps: AppDeps, today: DateString) {
  const pillars = await deps.repos.pillars.list(tx, {});
  const byId = new Map(pillars.map((p) => [p.id, p]));
  const latest = await deps.repos.checkins.latestDate(tx);
  let lowestPillarKey: string | null = null;
  if (latest) {
    const { ratings } = await deps.repos.checkins.get(tx, latest);
    const rated = ratings.flatMap((r) => { const p = byId.get(r.pillarId); return p ? [{ pillarId: r.pillarId, pillarKey: p.key, rating: r.rating, sortOrder: p.sortOrder }] : []; });
    lowestPillarKey = focalAreas(rated)[0]?.pillarKey ?? null;
  }
  const own = (await deps.repos.affirmations.list(tx)).map((a) => ({ text: a.text, pillarKey: a.pillarId ? (byId.get(a.pillarId)?.key ?? null) : null }));
  const seedForPillar = lowestPillarKey ? await deps.repos.affirmations.seedFor(tx, lowestPillarKey) : [];
  const seedGeneral = await deps.repos.affirmations.seedGeneral(tx);
  const w = selectWord({ date: today, lowestPillarKey, own, seedForPillar, seedGeneral });
  return w ? { date: today, ...w } : null;
}
```

```ts
import type { FastifyInstance } from "fastify";
import type { ZodTypeProvider } from "fastify-type-provider-zod";
import type { AppDeps } from "../app.js";
import { errorResponses } from "../contract/common.js";
import { Week, WeekParams } from "../contract/week.js";
import { validation, replyWithError } from "../errors/results.js";
import { userTx } from "./helpers.js";
import { isSunday, weekDates } from "../domain/dates.js";
import { nOf7 } from "../domain/routine.js";

export async function weekRoutes(app: FastifyInstance, deps: AppDeps) {
  const r = app.withTypeProvider<ZodTypeProvider>();
  r.get("/weeks/:sunday", { preHandler: app.authenticate, schema: { tags: ["week"], security: [{ bearer: [] }], params: WeekParams, response: { 200: Week, ...errorResponses } } }, async (req, reply) => {
    const { sunday } = req.params;
    if (!isSunday(sunday)) return replyWithError(reply, validation("The week must start on a Sunday"));
    const dates = weekDates(sunday);
    const last = dates[6]!;
    return userTx(req, deps)(async (tx) => {
      const items = await deps.repos.routine.listItems(tx, { includeInactive: true });
      const completions = await deps.repos.routine.completionsBetween(tx, sunday, last);
      const counts = nOf7(completions, dates);
      const ticked = new Set(completions.filter((c) => c.completed).map((c) => `${c.itemId}|${c.date}`));
      const pillars = await deps.repos.pillars.list(tx, { includeInactive: true });
      const { ratings, gratitudes } = await deps.repos.checkins.between(tx, sunday, last);
      return {
        sunday, dates,
        items: items.filter((i) => i.isActive || counts[i.id]).map((i) => ({ id: i.id, title: i.title, bucket: i.bucket, isActive: i.isActive, days: dates.map((d) => ticked.has(`${i.id}|${d}`)), nOf7: counts[i.id] ?? 0 })),
        pillars: pillars.map((p) => ({ id: p.id, key: p.key, name: p.name, ratings: dates.map((d) => ratings.find((x) => x.pillarId === p.id && x.date === d)?.rating ?? null) })),
        gratitudes: gratitudes.sort((a, b) => (a.date < b.date ? -1 : 1)).map((g) => ({ date: g.date, entry: g.entry })),
      };
    });
  });
}
```

```ts
import * as jose from "jose";
import type { Config } from "../config.js";
import { ok, err, unauthorized, type ApiResult } from "../errors/results.js";

export type Auth0Identity = { sub: string; email?: string };

export function createAuth0Verifier(config: Config, getKey?: jose.JWTVerifyGetKey) {
  const key = getKey ?? jose.createRemoteJWKSet(new URL(config.auth0.jwksUri), { timeoutDuration: config.auth0.jwksTimeoutMs });
  return async (token: string): Promise<ApiResult<Auth0Identity>> => {
    try {
      const { payload } = await jose.jwtVerify(token, key, { issuer: config.auth0.issuer, audience: config.auth0.audience });
      if (typeof payload.sub !== "string") return err(unauthorized("Auth0 token has no subject"));
      return ok({ sub: payload.sub, ...(typeof payload.email === "string" ? { email: payload.email } : {}) });
    } catch (e) {
      return err(unauthorized("Auth0 token rejected", { code: e instanceof jose.errors.JWTExpired ? "token_expired" : "token_invalid" }));
    }
  };
}
```

`apps/api/src/auth/exchange.ts`:
```ts
import { createClient } from "@supabase/supabase-js";
import { createHash } from "node:crypto";
import type { Config } from "../config.js";
import type { Db } from "../db/client.js";
import { ok, err, internal, type ApiResult, type ApiError } from "../errors/results.js";
import type { Auth0Identity } from "./auth0.js";

export type Session = { accessToken: string; refreshToken: string; expiresIn: number; tokenType: "bearer" };
export interface SupabaseAdmin {
  findUserIdByAuth0Sub(sub: string): Promise<string | null>;
  createUser(input: { email: string; auth0Sub: string }): Promise<{ id: string }>;
  mintSession(email: string): Promise<Session>;
  refresh(refreshToken: string): Promise<Session>;
}
export type ExchangeDeps = { verifyAuth0: (token: string) => Promise<ApiResult<Auth0Identity>>; admin: SupabaseAdmin };

/** Stable, non-personal address for Auth0 users who arrive without an email. */
export function syntheticEmail(sub: string): string {
  return `${createHash("sha256").update(sub).digest("hex").slice(0, 32)}@auth0.invalid`;
}

export async function exchange(deps: ExchangeDeps, auth0Token: string): Promise<ApiResult<Session & { userId: string }>> {
  const id = await deps.verifyAuth0(auth0Token);
  if (id.isErr()) return err(id.unwrapErr());
  const { sub, email } = id.unwrap();
  const address = email ?? syntheticEmail(sub);
  let userId = await deps.admin.findUserIdByAuth0Sub(sub);
  if (!userId) {
    try { userId = (await deps.admin.createUser({ email: address, auth0Sub: sub })).id; }
    catch (e) {
      if ((e as { code?: string }).code !== "23505") return err(internal("Could not create account") as ApiError);
      userId = await deps.admin.findUserIdByAuth0Sub(sub);
      if (!userId) return err(internal("Could not create account"));
    }
  }
  const emailForMint = email ?? syntheticEmail(sub);
  const session = await deps.admin.mintSession(emailForMint);
  return ok({ userId, ...session });
}

export function createSupabaseAdmin(config: Config, db: Db): SupabaseAdmin {
  const admin = createClient(config.supabase.url, config.supabase.serviceRoleKey, { auth: { persistSession: false, autoRefreshToken: false } });
  const pub = createClient(config.supabase.url, config.supabase.anonKey, { auth: { persistSession: false, autoRefreshToken: false } });
  const toSession = (s: { access_token: string; refresh_token: string; expires_in: number }): Session => ({ accessToken: s.access_token, refreshToken: s.refresh_token, expiresIn: s.expires_in, tokenType: "bearer" });
  return {
    async findUserIdByAuth0Sub(sub) {
      const rows = await db.sql<{ id: string }[]>`select id from auth.users where raw_app_meta_data->>'auth0_sub' = ${sub}`;
      return rows[0]?.id ?? null;
    },
    async createUser({ email, auth0Sub }) {
      const { data, error } = await admin.auth.admin.createUser({ email, email_confirm: true, app_metadata: { auth0_sub: auth0Sub } });
      if (error) throw Object.assign(new Error(error.message), { code: /already|duplicate|unique/i.test(error.message) ? "23505" : error.code });
      return { id: data.user.id };
    },
    async mintSession(email) {
      const link = await admin.auth.admin.generateLink({ type: "magiclink", email });
      if (link.error) throw link.error;
      const v = await pub.auth.verifyOtp({ token_hash: link.data.properties.hashed_token, type: "magiclink" });
      if (v.error || !v.data.session) throw v.error ?? new Error("no session");
      return toSession(v.data.session);
    },
    async refresh(refreshToken) {
      const { data, error } = await pub.auth.refreshSession({ refresh_token: refreshToken });
      if (error || !data.session) throw error ?? new Error("no session");
      return toSession(data.session);
    },
  };
}
```
