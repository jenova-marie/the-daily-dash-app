## 2. Matrix — source feature (row) × target feature (column)

Cell keywords: **link** deep link with query string · **route** redirect or landing rule · **widget** the row feature supplies a Dashboard widget · **embed** the row feature renders the column feature's component or card · **w/t** completion or date write-through on the column feature's entity · **entity** a shared entity or field · **fn** a backend function call · **wf** an entity-triggered or scheduled workflow · **event** a window event or global flag · **pref** an account or device preference read or written · **export** a print/email binding · **AI** a language-model touchpoint · **seed** seed rows written · **text** a plain-text pointer or a `[Described]` claim only · **dialog** a shared edit dialog opened across features. A blank cell means no interaction observed. Detail and citations are in §3, keyed by row id.
